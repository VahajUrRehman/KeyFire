# Shotgun kit credits

Sounds are from the "CC0 Public Domain Sounds" collection
(https://github.com/lavenderdotpet/CC0-Public-Domain-Sounds), released under CC0 1.0 (public domain).
They were trimmed, peak/level-matched and converted to Ogg Vorbis. Nothing else changed.

| File | Source file in the collection |
|---|---|
| blast-01.ogg | 25-CC0-bang-sfx/shot_01.ogg |
| blast-02.ogg | 25-CC0-bang-sfx/shot_03.ogg |
| blast-03.ogg | 25-CC0-bang-sfx/bang_09.ogg |
| blast-04.ogg | 25-CC0-bang-sfx/bang_01.ogg |
| blast-05.ogg | 25-CC0-bang-sfx/shot_02.ogg |
| boom-01.ogg  | 25-CC0-bang-sfx/bang_03.ogg |
| boom-02.ogg  | 25-CC0-bang-sfx/cannon_01.ogg |

Drop your own files named blast-*, boom-*, pump-*, shell-* into the app's "kit" data folder
(Settings > Open kit folder) and they replace the bundled ones for that role.
